# Les fiches des élèves

Chaque élève ajoute ici **sa** fiche, dans un fichier nommé d'après son pseudonyme GitHub :
`eleves/ton-pseudo.md`.

Une fiche contient seulement :

- ton pseudonyme GitHub ;
- ton langage de programmation préféré, ou celui que tu voudrais apprendre ;
- une phrase de ton choix.

Aucun nom, aucun prénom, aucune adresse, aucune photo.
